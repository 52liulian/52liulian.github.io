# 52liulian 个人主页

个人主页项目，使用原生 HTML/CSS/JavaScript 开发。

## 技术栈

- HTML5
- CSS3
- JavaScript

## 功能特性

- 终端风格主页
- 3D项目卡片展示
- 自定义光标跟随效果
- 全屏滚动布局
- 日/夜主题切换
- 响应式设计

## 文件结构

```
├── index.html          # 主页HTML
├── static/
│   ├── css/
│   │   ├── root.css    # 主题变量
│   │   └── style.css   # 样式文件
│   ├── js/
│   │   └── script.js   # JavaScript功能
│   ├── fonts/          # 字体文件
│   ├── svg/            # SVG图标
│   └── img/            # 图片资源
├── CNAME               # GitHub Pages配置
└── README.md           # 说明文档
```

## 使用方式

直接打开 index.html 或部署到静态服务器。
